<|start_of_focus|># Changelog

All notable changes will be documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.2] - 2026-09-01

### Changed

- Repository renamed from `wlkngkr` to `cpmf-uiprc-diag`; all project URLs
  updated. The distribution name on PyPI is unchanged.

## [0.1.1] - 2025-11-25

### Fixed

- Probes no longer silently truncate data.

## [0.1.0] - 2025-11-25

### Added
- Initial release of `wlkngkr` with system + user probes.
- CLI commands for listing and running probes via Typer.
- `ProbeRunner`, Pydantic models, and registry utilities.
- Basic documentation (`docs/`) and pytest smoke tests.

The repository was renamed from `wlkngkr` to `cpmf-uiprc-diag` after 0.1.1.
The distribution name on PyPI stays `wlkngkr`; only the repository moved, and
GitHub redirects the old URLs.
